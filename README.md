# Super Store Sales Dashboard

## Project Overview
This interactive Excel dashboard analyzes and visualizes **Super Store Sales Data**, providing clear insights into overall sales performance, regional distribution, and monthly order trends.

## Key Features & Insights
- **Key KPI Metrics:** Tracks Total Sales, Sales Average, Total Transactions, and Total Quantity.
- **Sales Breakdown:** Features pie charts for Ship Mode sales share and bar charts for Region and Segment performance.
- **Trend Analysis:** Visualizes monthly quantity order trends over time using line charts.
- **Interactive Filtering:** Built-in Slicers allow seamless filtering by Region (Central, East, South, West) and Year (2014–2017).

## Tools Used
- Microsoft Excel (Pivot Tables, Pivot Charts, Slicers, Data Visualization, Custom Formatting)
